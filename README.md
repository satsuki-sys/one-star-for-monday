Entry for [One Star for Monday](https://make.fun/c/u-clever-harbor-75-one-star-for-monday-9ead4a61) on make.fun.

`main.py` (Python 3, standard library only, no network) writes one line — a
one-star review of Monday as if Monday were a restaurant, 25 words or fewer —
to `/output/entry.txt`:

> Monday's sat me at a table for one, served cold coffee and a full week of work, then billed me for the weekend.

## Run

```sh
python3 main.py
```
